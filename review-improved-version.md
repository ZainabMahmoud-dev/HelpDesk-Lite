# Improved Version

## HelpDesk Lite — Stakeholder Decision Brief

### Current Situation

Internal support requests are currently received through multiple channels. This creates several operational problems:

- Ownership can be unclear.
- Follow-up is inconsistent.
- Users may need to repeat information.
- Managers have limited visibility into open, delayed, and completed requests.

### Proposed Solution

HelpDesk Lite centralizes internal support requests into a single ticketing workspace.

Each request becomes a trackable ticket with:

- A clear owner
- A priority
- A current status
- Progress toward resolution

### Proposed Workflow

```text
Create Ticket
      ↓
Assign Owner
      ↓
Set Priority
      ↓
Work on Request
      ↓
Resolve
      ↓
