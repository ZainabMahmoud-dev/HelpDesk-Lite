# HelpDesk Lite — Message Structure

## Main Message

HelpDesk Lite provides a centralized internal support ticketing workspace that improves ticket ownership, follow-up, and visibility by managing support requests through a clear and trackable workflow.

## Message Hierarchy

### 1. Current Problem

Support requests are currently handled through multiple channels, which can result in:

- Unclear ownership
- Inconsistent follow-up
- Repeated clarification
- Limited visibility into open, delayed, and completed requests

### 2. Proposed Solution

HelpDesk Lite centralizes support requests into trackable tickets.

Each ticket should provide:

- Clear ownership
- Priority
- Current status
- Progress tracking
